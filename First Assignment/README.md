Project Name: Player World

Description: An application that can create a player; a character is generated for the player, and an item is issued.


How to run:

https://play.kotlinlang.org/


What demonstrated:

interfaces - IMovable for movable world objects.

classes and inheritance - WorldItem base class, and Pan, Wardrobe.

map - world with items, player ids

lambda-factory - create items

data classes and sealed classes - Player, RegistrationResult, CreationStatus (simulating)

sets - unique nicknames

lists - list of players, items

coroutines and suspend-func - CharacterCreator (create() and assembling starter items)
